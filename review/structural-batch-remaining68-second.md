# 正文组件结构复用：剩余 68 项的第二轮

本轮从 51 个短文案机械试填可导出的候选中，核对原生图形含义、字段、阅读顺序，并用与源业务无关的项目工作内容实际填充和 PowerPoint 渲染。验证图位于工作区 `_验证输出/正文结构匹配试点/剩余68项机械试填`。

| 组件 | 开放边界 |
| --- | --- |
| `content-tech-042` | 四项闭环；每项标题、正文，另需真实中心结论；按左上、左下、右上、右下映射源槽 |
| `content-tech-045` | 四步流程；每项标题、正文；顶部可见槽位写入真实页标题，仅步骤序号自动生成 |
| `content-tech-081` | 三层自上而下的漏斗；每层标题和正文，要求明确层级次序 |

上述 3 项经通用短文案填充、实际 PowerPoint 渲染和图形含义复核，标记 `pilot_verified`，可进入自动选稿。长文案仍必须逐次通过组件容量检查，不据短文案渲染放行。其余 65 项继续保持待验证或专用限制；机械填充成功并不等于可跨场景复用。`content-tech-046` 和 `content-tech-066` 的标题已写入 PPTX 但 PowerPoint 导出时不可见，暂缓激活，待修复源页标题可见性。固定业务图标、源稿百分数、领域专用标题以及无法明确对应的关系图仍不自动解绑。
